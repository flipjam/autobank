# Public Evidence Directory

Only public-safe, redacted evidence may be committed here.

Every committed artifact should have a corresponding entry in `EVIDENCE_INDEX.md` that states what the artifact proves, its source and timestamp, integrity information when practical, and all redactions applied.

Do not store credentials, browser/session data, customer personal information, banking or tax details, private account records, or unredacted screenshots here. Sensitive originals belong only in the ignored local `private-evidence/` directory or another owner-approved secure location.

Prefer small text summaries, hashes, public URLs, test outputs, and redacted images over full private source material.
