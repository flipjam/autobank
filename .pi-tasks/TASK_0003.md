## refined prompt

GOAL
Prove serialization of model requests in the Autobank workspace (`C:\Projects\autobank`, `flipjam/autobank`, branch `main`) using **direct CLI overrides** exclusively — every `pi` invocation must use `--provider <name>` and `--model <name>` flags instead of `PI_PROVIDER`/`PI_MODEL` environment variables. Demonstrate:

1. Serialized `pi --list-models` calls (sequential, no overlap).
2. Serialized `pi --print` calls (sequential, no overlap).
3. Provider/model direct override proof (`--provider openai-codex --model gpt-5.3-codex-spark`).
4. Timeout/failure detection and subsequent retry after terminal completion.
5. Default-context proof (no explicit overrides, using runtime defaults) run last to confirm both paths work.

CONSTRAINTS
- This is bounded setup/testing only. No campaign/revenue work, no external data mutation beyond commits and pushes to `flipjam/autobank`.
- Use **direct CLI overrides** (`--provider`, `--model`) on every `pi` invocation. Do not use `PI_PROVIDER` or `PI_MODEL` environment variables for model routing.
- One active model request at a time. No fan-out, no background processes, no overlapping `pi` invocations.
- Commands must execute sequentially in a single shell script or function where each starts only after the previous exits.
- `REQ-20260727-002` remains a production-readiness gate; it does not block this bounded serialization test.
- Do not modify `AUTOBANK_POLICY.md`, `CONTROL.json`, `MISSION.md`, or `AUTHORIZED_RESOURCES.md`.

KNOWN-UNKNOWNS
- Does `pi --provider openai-codex --model gpt-5.3-codex-spark --print` behave identically to `PI_PROVIDER=openai-codex PI_MODEL=gpt-5.3-codex-spark pi --print` in terms of serialization semantics?
- Does the shell `timeout` command reliably capture the timeout exit code (124) without killing the `pi` process tree mid-response?
- Is the explicit `--no-tools` flag required for clean `--print` behavior in all contexts?
- Are there any implicit retry or reconnect mechanisms inside `pi` that could cause a second request to start before the first truly completes?

EXTERNAL-DEPENDENCIES
- `pi` CLI (local inference runtime)
- Bash-compatible shell
- `timeout` command (coreutils)
- Subscription-backed model provider (`openai-codex` / `gpt-5.3-codex-spark`) accessible via direct CLI override
